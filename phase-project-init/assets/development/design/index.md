# Design Catalog

The linked documents are the canonical current-state source for their part of
the system. Read the relevant design concept before consulting phase history or
source code — the design layer says how things work *now*, while phase history
says how they came to.

Add one entry per concept as you create it, grouped under whatever headings
suit the system.
